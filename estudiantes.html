Partes PC

  1. CPU procesa datos.
  2. RAM almacena temporalmente.
  3. Disco guarda información.
  4. Fuente da energía.
  5. Placa conecta todo.

Python

  1. print() muestra información.
  2. input() recibe datos.
  3. int() convierte valores.
  4. Las variables guardan datos.
  5. Es fácil de aprender.

Redes

  1. LAN es red local.
  2. WAN es red global.
  3. Router distribuye internet.
  4. Permite compartir datos.
  5. Conecta equipos.

Mantenimiento

  1. Limpia el polvo.
  2. Actualiza sistema.
  3. Evita virus.
  4. Revisa cables.
  5. Cuida el equipo.

Cables

  1. RJ45: internet.
  2. SATA: discos duros.
  3. USB: conexión general.
  4. HDMI: video y audio.
  5. Coaxial: señal.
